## Overview

Multi-agent patterns in Meko allow you to design systems where multiple agents share knowledge through shared datapacks, while maintaining private memory in their own datapacks. This guide will cover shared vs. private datapack strategies, cross-agent knowledge sharing, and orchestration patterns.
