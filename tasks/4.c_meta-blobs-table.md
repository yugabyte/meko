# Phase 4c — Full-overwrite blobs → `pageserver.meta`

Everything that isn't a rel-page or SLRU block lives here:

- Rel-size sentinels
- Dir listings (TenantDir / DbDir / RelDir / SlruDir)
- Aux files
- Repl origins
- Two-phase
- SLRU dir + segment-size sentinels

Single row per `(tenant, timeline, key, lsn)`; reads = LIMIT 1 at
`lsn DESC`; no walredo.

`TimelineWriter::put_batch` now sends the entire batch to
`PageWriter` — the layer-file write is skipped unconditionally.

## End-state verification

A fresh tenant with INSERT 500 + UPDATE×2 + multixact + CREATE INDEX
produces: `pages=2889, slru_pages=3, meta=968, blobs=2` (just
`initdb.tar.zst` + `tenant-manifest.json` — bootstrap artifacts
handled outside `put_batch`).
