# Phase 3f — `UnifiedPages` (in-RAM rel-page buffer + post-flush cache)

One in-RAM structure that replaces the prior `Vec<PageRow>` buffer
that was drained on flush.

- Each entry has a `durable` bit; flush is a cursor flip
  (`mark_first_n_flushed`) — no copy, no move.
- Durable entries linger in a FIFO until `total_bytes` exceeds
  `read_cache_bytes` (default 1 GiB), at which point they evict FIFO.
- Pre-flush entries are pinned regardless.

Two lookup APIs:
- `lookup_chain` (durable + pre-flush, used by compute reads).
- `lookup_chain_durable` (cache + YB only, used by the materialiser
  to dodge the crash + replay double-apply hazard).

10 unit tests covering insert/lookup/mark/evict/trim/snapshot.
