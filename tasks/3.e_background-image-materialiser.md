# Phase 3e — Background image materialiser (at-write trigger)

`PageWriter::put` counts consecutive non-anchor deltas per key under
the same RwLock as the buffer; on crossing `image_chain_limit`
(default 10) `try_send`s `MaterializeJob { key, target_lsn }` to a
bounded mpsc.

Worker (`ImageMaterializer::spawn`, one per timeline):
- Reads via `PageWriter::read_chain_durable` (cache + PageStore,
  EXCLUDES pre-flush — see write-path §7 for the correctness reason).
- Walredoes.
- `PageStore::put_pages` the image.
- `PageWriter::install_materialized_image` trims the cache for that
  key up to the image LSN and inserts the new image as a durable
  entry.

Five trigger-logic unit tests cover threshold dispatch, image /
`will_init` reset, per-key independence, and limit=0 disable.
