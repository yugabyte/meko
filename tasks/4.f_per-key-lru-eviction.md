# Phase 4f — Per-key LRU eviction in `UnifiedPages`

Today eviction is per-row FIFO; mid-chain gaps are possible when
stale FIFO refs let a delta be popped while its image-anchor remains.
That forces the `evicted_below` watermark + completeness check.

With the materialiser keeping every key's chain ≤ `image_chain_limit`+1,
the natural eviction unit is the whole key — drop `KeyState` entirely,
no holes possible.

## Plan

- Replace both FIFOs with a single key-keyed LRU.
- Delete `evicted_below` and stale-ref machinery.
- Pin keys with unflushed rows.
