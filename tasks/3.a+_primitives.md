# Phase 3a+ — Primitives feeding Phase 3b

Two primitives that Phase 3b will reach for:

- `PageWriter::spawn_flusher(tick)` returns a `FlushTask`
  (`JoinHandle` + `CancellationToken`) for the per-timeline
  background flusher; does a final `flush()` on cancel.
- `extract_triples(SerializedValueBatch)` decodes a walingest batch
  into the `(Key, Lsn, Value)` triples `PageWriter::put` consumes.

Both with tests.
