# Phase 3d — Schema reshape + design pivot

`pageserver.pages` PK becomes
`((tenant…forknum) HASH, blknum, is_image, lsn DESC)`: typed columns +
per-block image clustering.

Reads become an image-anchored CTE:
- **Fast path:** latest image ≤ target + deltas above.
- **Slow path:** walk back to the `will_init` delta.

Writes drop all walredo at write time — pure passthrough.
`image_rule.rs` + `page_materializer.rs` deleted.

The "10-delta invariant" stops being a write-time contract; chain
bounding moves to a background image materialiser (Phase 3e).

End-to-end verified with `CREATE TABLE / INSERT 1000 / UPDATE×3 /
SELECT` against compute; long chains (400+ rows on hot blocks) read
correctly via the slow path.
