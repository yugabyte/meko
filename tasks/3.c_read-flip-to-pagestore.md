# Phase 3c — Read flip to PageStore

`Timeline::get_vectored_impl` branches on `self.page_writer`: when
yb-pageserver mode is active, reads go through
`get_vectored_via_page_writer` — per-key parallel
`PageWriter::read_chain` → `chain_to_value_reconstruct_state`
(image-anchor → img, deltas → records) → `Timeline::reconstruct_value`
(walredo).

The LayerMap walk is bypassed entirely. Upstream pageserver behaviour
preserved when `page_writer` is `None`.

Layer-file path became dead code from the read perspective at this
point; still populated by 3b dual-write until Phase 4a removed both.
