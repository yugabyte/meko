This page covers the Meko portal, API, and platform. For Installer, MCP server, and agent skills updates, see the [Installer release notes](../../installer/).

### New features

#### Portal

- **[Group datapacks in a project](../../../architecture/core-concepts/datapacks/#group-datapacks-in-a-project)** - Open **Projects** and click **New Project**. Enter a **Name** and click **Create project**. Organize datapacks in folders. View collective learnings across the entire project.

- **[Tier limit reporting](../../../architecture/core-concepts/datapacks/#reach-a-tier-limit)** - When you reach a limit, Meko shows a banner with the limit you reached, such as `10 / 10 datapacks used`. To upgrade from Free, choose **Upgrade to Standard**. To upgrade from Standard, choose **Talk to our team**.

### Fixed

#### Portal

- **[What a viewer can do](../../../architecture/core-concepts/datapacks/#what-a-viewer-can-do)** - A **Viewer** can search a shared datapack. Creating or changing a conversation or memory through MCP returns `read_only_access`. Search results do not name who wrote a turn.

- **[Agentic coding review lab](../../../examples/labs/#agentic-coding-review-adlc)** - When the review comes back as malformed JSON, the lab shows the review text. It does not show **No blocking issues found**. If the run has no text, the lab says `The run returned no text either. Run the review again.`

#### Platform

- **[Create a datapack](../../../architecture/core-concepts/datapacks/#create-a-datapack)** - If tracing setup fails, creation stops with `Could not finish setting up the datapack; nothing was created. Please retry.` Nothing is left behind. You can create more than one datapack at the same time, up to your plan's datapack cap.

- **[Delete a datapack](../../../architecture/core-concepts/datapacks/#delete-a-datapack)** - You can now delete a datapack even if tracing is unavailable.
