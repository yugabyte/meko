### New Features

#### Platform

- **Early Access launch** — Meko is live. Sign up at [mekodata.ai](https://mekodata.ai).
- **Default datapack on signup** — every new account gets a default datapack pre-provisioned. MCP endpoint immediately available at `https://mcp.mekodata.ai/v1/{account_id}/{datapack_name}`.

#### MCP Server

- **`memory_*` tools** — `memory_add`, `memory_search`, `memory_get_all`, `memory_delete_by_id`, `memory_delete_all`.
- **`knowledgebase_*` tools** — `trigger_knowledge_base_build`, `check_index_status`, `add_source_to_index`.
- **`db_*` tools** — `run_read_only_query`, `run_write_query`, `summarize_database`.
- **`conversation_*` tools** — `conversation_create`, `conversation_add_message`, `conversation_get`, `conversation_list`.
