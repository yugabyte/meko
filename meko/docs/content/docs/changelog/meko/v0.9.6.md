This page covers the Meko portal, API, and platform. For Installer, MCP server, and agent skills updates, see the [Installer release notes](../../installer/).

### New features

#### Portal

- **Usage** — A dedicated Usage page shows live consumed versus plan limits for datapacks, conversations, workbench tokens, knowledge-base storage, and MCP memory and search activity. Open it anytime from the portal navigation to see where you stand.
- **Request account deletion** — Settings includes a request-deletion flow that opens a support ticket. Deletion remains human-reviewed: identity and owned datapacks are verified before anything is removed.
- **Artifacts in the portal** — Each datapack has an Artifacts page, linked from a card on the datapack detail page, so agent-generated files are easy to find and download alongside memories and knowledge-base documents.
- **Live knowledge-base file status** — Uploaded files progress through queued, processing, and ready as indexing completes, so you can see when a document is available to search. First-upload details such as size and uploader stay accurate for existing files as well.

### Improvements

#### Platform

- **Performance and reliability** — Various performance and reliability improvements across the MCP server, including more resilient handling of transient failures and safer conversation writes under retry.

### Fixed

#### Portal

- **Invite sign-in stuck on “Signing out…”** — New users accepting an invite no longer get stuck after setting their password; they reach sign-in as expected.
